# Scenario script archive

The dialogue reader at `/scenario-script` uses https://latale.wiki/scenario-script and its `/api/scenario-story/{id}` responses. It is separate from the objective walkthrough at `/scenario`.

Run `node scripts/sync-scenario-scripts.mjs --output .cache/scenario-script-review` to stage the current Korean source. The importer decodes the page's JSON without evaluating scripts, fetches every story with bounded concurrency and request retries, and validates identifiers, metadata, recursive branches and source line counts before writing. It preserves original strings, whitespace, `%s` placeholders, source order, and unknown fields. Review the snapshot counts, per-story checksums and differences before publishing with `node scripts/sync-scenario-scripts.mjs`.

The source lives in `static/data/scenario-script/ko/index.json` and `ko/stories/{id}.json`. The dedicated `ko` directory is staged completely and replaced with rollback if promotion fails. An output directory containing unrelated files is rejected. English files, the objective walkthrough, other tool data, and shared portraits are outside the importer's scope. If an English index exists, a changed source checksum stops default publication until its `translation.sourceSha256` has been updated after review; review-directory imports always remain available. The importer does not translate text.

The September 12, 2026 snapshot contains 143 stories, 863 steps, 1,453 scenes, 50,651 dialogue lines and 172 choices. Every story's source update date is August 5, 2026. The source page provides base levels but no Super Levels. Its source index interleaves main and side stories; preserve that order rather than sorting by numeric IDs. The source has repeated dialogue and scene IDs for reused branches, so identifiers must not be treated as globally unique DOM anchors.

Stories have `steps[].scenes[].lines[]`; dialogue lines retain `id`, `speaker` and `text`. Optional `choices[]` contain `text`, `goto` and recursively nested `lines[]`. Preserve `goto` and every branch even when it reuses dialogue. Empty speakers represent narration. `%s` is the character name placeholder; the source also contains `%S` speaker variants. Decode literal escaped line breaks only for display, and render all source text as plain text.

The index maps Korean speaker names to portrait IDs. All 344 distinct portraits currently exist at `static/npc/{id}.png`; the source path for new assets is `https://latale.wiki/icons/npc/{id}.png`. Multiple exact speaker spellings can share a portrait. A new portrait should be added separately without removing existing shared assets.

English must be freshly translated from the current Korean source. Do not recover retired dialogue translations or revive the previous bulk machine-translation pipeline. Fresh translations are kept separately in `translations/{id}.json`, keyed by exact original text and tied to the story's SHA-256 checksum; the translation assembly/check workflow validates coverage and preserves source structure. The SHA-256 in `ko/index.json` covers `JSON.stringify({index, speakers, chapters, stories})`, with stories in the current source index order. Per-story checksums cover `JSON.stringify(story)`; timestamps are excluded.

Run `node --test tests/scenario-script-sync.test.mjs` after importer changes and the separate translation checker before releasing English content. In the browser, check chapter/type/search filters, character-name substitution, story and step links, nested choices, original-language switching and responsive layouts.
